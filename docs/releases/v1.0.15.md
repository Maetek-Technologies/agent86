Adds a sign-in step so agent86 can be listed in the ACP registry.

- **`agent86 auth`.** An interactive setup: it lists the providers that take an API key (marking which already have one), asks which to set up, reads the key with input hidden, and stores it in the OS keyring, the same place as `agent86 keys set`. It needs a terminal.
- **Authentication in `agent86 acp`.** The handshake now offers one terminal sign-in method that runs `agent86 auth`, which the ACP registry requires. Nothing is refused for lack of it: a key in the environment or the keyring works as before.

Nothing else changes.
