Thinking models that get stuck repeating themselves are now stopped, stray tags no longer show up in their reasoning, and there are Linux builds for ARM64 (including the Raspberry Pi) and for older Linux systems.

## What's new

- **Reasoning loops are stopped:** some hosts serve a thinking model with a reasoning parser that doesn't match its template. The model then often repeats one short piece of text until it hits the output cap, which can cost thousands of tokens and a minute of waiting. agent86 now notices when the reasoning has become the same text over and over, and stops it, saying `[the model's reasoning was repeating itself; stopped it]`. The model is then asked once more for its answer; if that reply is empty too, the reasoning from before the loop stands in for the answer. This works with OpenAI-compatible providers (including OpenRouter) and Ollama.
- **No more stray tags in reasoning:** the same hosts leave the model's own closing tag (such as `</think>` or `</trans>`) in its reasoning. A line holding only a closing tag that nothing opened is now dropped.
- **OpenRouter provider routing:** you can now keep a model off an OpenRouter host that serves it badly, or choose its host in other ways. `[providers.<name>.routing]` is sent as OpenRouter's `provider` preferences:

  ```toml
  [providers.openrouter.routing]
  ignore = ["Phala"]
  ```

- **Linux ARM64 and older Linux:** there is now a build for 64-bit ARM Linux, including 64-bit Raspberry Pi OS. Both Linux builds now need glibc 2.35 or newer rather than 2.39, so they run on Ubuntu 22.04, Debian 12, and Raspberry Pi OS Bookworm. The ARM64 build passes the full test suite, but hasn't yet been run on a Raspberry Pi.

The first three are deliberate additions beyond Python agent86. Everything else behaves as in 1.0.4.

## Install

Download the archive for your platform, extract it, and put `agent86` (or `agent86.exe`) on your `PATH`.

| Platform | Archive |
|---|---|
| Linux x86_64 (glibc 2.35+) | `agent86-v1.0.5-x86_64-unknown-linux-gnu.tar.gz` |
| Linux ARM64, including Raspberry Pi (glibc 2.35+) | `agent86-v1.0.5-aarch64-unknown-linux-gnu.tar.gz` |
| macOS Apple silicon | `agent86-v1.0.5-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `agent86-v1.0.5-x86_64-apple-darwin.tar.gz` |
| Windows x86_64 | `agent86-v1.0.5-x86_64-pc-windows-msvc.zip` |

Each archive has a `.sha256` file next to it. The binaries are not signed:

- **macOS:** clear the quarantine flag once with `xattr -d com.apple.quarantine agent86`.
- **Windows:** SmartScreen may ask you to confirm the first time you run it.
- **Raspberry Pi:** a headless Pi usually has no Secret Service, so `agent86 keys set` may fail there. Put the key in the provider's environment variable instead (for example `OPENROUTER_API_KEY`).

To build from source instead, use Rust 1.88 or newer: `cargo install --git https://github.com/tdfleming/agent-86-rs --tag v1.0.5`.
