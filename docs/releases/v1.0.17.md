Session lists now show each session under the folder it ran in, and you can rename a session.

## Session lists are right per folder

- **Every session records its folder.** agent86 has always kept the folder of each editor session, so editors could list a project's sessions. Sessions started at a terminal (`agent86`, `agent86 run`) were not recorded, so a client that asked for one folder's sessions got every terminal session as well. Now every session records the folder it ran in: a terminal session once it has its first message, and any session again whenever it is resumed (`agent86 --resume`, `/resume`, or the session picker).
- **No more guessing.** A session whose folder is not known is left out of a list for one folder, instead of being shown under whichever folder the listing started in. A list of all sessions still includes it, marked as having no known folder (`_meta: {"agent86": {"cwdKnown": false}}`, described in [the ACP guide](https://github.com/Maetek-Technologies/agent86/blob/main/docs/ACP.md#session-list-and-working-directories)).
- **Safe with several windows open.** Several agent86 processes can record folders at the same moment without losing each other's entries.

**Sessions saved before 1.0.17** at a terminal, or by the Python agent86, have no recorded folder, and nothing in them says where they ran. They no longer appear in folder lists, such as an editor's or agent86-web's session list for a project. To bring one back, resume it once at a terminal from its project folder (`agent86 --resume <id>` there). From then on it is listed under that folder.

## Rename a session

- **`/rename <title>`** gives the current session a new name. **`/rename`** alone shows the current name. Before, a session was named once, from its first message, and could not be renamed.
- **Everywhere.** It works in the interactive interface, the plain loop, and editors over ACP. In an editor it is answered without a model turn, and agent86 tells the editor the new title so its list updates straight away. The new name shows in `/sessions`, the `/resume` picker, and editors' session lists, and later turns keep it.
- **Tidy titles.** Leading and trailing spaces are removed, only the first line is kept, control and text-direction characters are dropped, and the name is capped at 200 characters. A name with nothing left is refused.
- The rename is not part of the conversation: the model never sees it.
