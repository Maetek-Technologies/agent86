The rest of the security fixes, and a newer machine-learning library underneath.

## Security fixes

- **`web_fetch` stays off more internal addresses.** It now refuses the 100.64.0.0/10 range, which holds carrier-grade NAT, Tailscale peers, and Alibaba Cloud's metadata service, and the old 6to4 relay range. It also ignores `HTTP_PROXY` and `HTTPS_PROXY`: a proxy looks the host up again itself, which would get around the address check.
- **Hostile pages and commands can't exhaust the machine.**
  - A page full of unclosed tags no longer freezes the agent while it is reduced to text.
  - A command that prints endlessly keeps at most 8 MB per stream.
  - `read_file` reads a huge file only as far as it will show.
  - An `@mention` of a pipe or device is refused instead of waiting forever.
- **File writes are safer.**
  - `write_file` and `edit_file` write a new copy and swap it in, so a crash mid-write leaves the old file whole.
  - Writing over a binary file is called an overwrite in the approval prompt, with its size, instead of "new file".
- **The Docker sandbox runs with fewer privileges.** Containers drop every capability except the six needed to write your workspace and install packages, and setuid programs inside them gain nothing.
- **Secrets are harder to misuse.**
  - The model can't request a secret under a name like `PATH`, `LD_PRELOAD`, or `NODE_OPTIONS`, which would change how programs run.
  - Values shorter than 6 characters are refused, because hiding them would rewrite ordinary text.
  - `/secret NAME` still accepts any valid name you choose.
- **Model downloads are checked.** The embedding model's files are verified against the sizes and SHA-256 hashes Hugging Face lists, and a file that doesn't match never reaches the cache.

## Also

- **Timeouts keep more output.** A command that times out keeps what it had already printed, in the Docker sandbox too.
- **`run --yes` warns once** that commands will run without asking, unless the Docker sandbox contains them.
- **Smaller fixes:**
  - `&amp;lt;` on a fetched page now reads as `&lt;`.
  - `tool_timeout_s = 0` is reported as an invalid setting instead of making every command time out at once.
  - Pasting a key that starts with a smart quote no longer crashes `agent86 keys set`.
- **candle 0.11** now runs the local embedding model. This clears five security advisories on the zip library it used to bring in, which agent86 never actually used. Recall gives the same results: the model's vectors match sentence-transformers as before.

## If you build from source

Building agent86 now needs **Rust 1.94** or newer (it was 1.88), because candle 0.11 requires it. The npm package and the release archives are unaffected.

## Install

```sh
npm install -g agent86
```

Or download the archive for your platform, extract it, and put `agent86` (or `agent86.exe`) on your `PATH`.
