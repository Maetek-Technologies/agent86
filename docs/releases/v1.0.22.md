You can now see what agent86 has remembered, one fact or episode at a time, keep the ones that matter from ever being pruned, and delete the ones that are wrong, from the terminal or from an editor or client over ACP.

## Memory you can list, pin, and forget

- **List.** `agent86 memory list` shows the stored facts (what the agent keeps with `remember`), newest first, with their ids. `--episodes` lists episodes instead: one per finished turn, with its session, task, and outcome, which agent86 recalls into similar later tasks. `--pinned` shows only pinned entries, and `-n` sets how many to show (20 by default, negative for all).
- **Pin.** `agent86 memory pin <id>` keeps a fact from ever being removed by `agent86 memory prune` or by the retention limits applied at startup, and `unpin` undoes it. Add `--episode` for an episode's id; facts and episodes are numbered separately. Pinned entries don't count toward `--keep-last` or `[memory] retention_max_episodes`.
- **Forget.** `agent86 memory forget <id>` deletes a fact as before, and `--episode` now deletes an episode, so a bad outcome stops being recalled into later tasks.
- **Shared with Python.** Pins are kept in a table of agent86's own in the memory database, and the facts, episodes, and sessions themselves are unchanged, so the Python implementation still reads the database. Python doesn't know about pins, though, so its own pruning still removes pinned entries.

## Memory in editors and clients

- Clients such as agent86-web can list, pin, unpin, and forget the same facts and episodes for an open session, through three new ACP extension methods. Text from the session's secret vault comes back as `${secret:NAME}`, as everywhere else a client sees.

## For client authors

- `initialize` now lists `agentCapabilities._meta["com.maetek.agent86/memory"] = {"version": 1}`.
- The methods are `_com.maetek.agent86/memory/list` (paged with `limit` and `cursor`), `_com.maetek.agent86/memory/pin`, and `_com.maetek.agent86/memory/forget`. They are requests the client makes when it wants to, so no client capability is needed, and other clients see no change apart from the advertisement. The format is described in [the ACP guide](https://github.com/Maetek-Technologies/agent86/blob/main/docs/ACP.md#agent86s-memory-an-extension).

`agent86 run`, the terminal interface, and the existing `memory` commands behave as before.
