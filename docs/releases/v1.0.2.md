Ollama models now get the context window they were trained for, instead of always 8k.

## What's new

- **Ollama context windows follow the model:** agent86 asks Ollama (`/api/show`) how much context the model was trained for and uses that, up to a cap of 32768 tokens. A model trained for less gets its own full window. The status line and conversation compaction use the same figure, so the window you see is the one Ollama loads.
- **A configurable cap:** set `num_ctx_max` under `[providers.ollama]` to allow more (or less). Ollama allocates the whole window up front, so a model's full 256k can spill out of GPU memory; raise the cap to what your GPU can hold.
- **A fixed size still wins:** setting `num_ctx` under `[providers.ollama]` asks for exactly that size, without asking Ollama about the model. When Ollama cannot report a size, 8192 is used, as before.

This is a deliberate difference from Python agent86, which always asks Ollama for 8192. Everything else behaves as in 1.0.1.

## Install

Download the archive for your platform, extract it, and put `agent86` (or `agent86.exe`) on your `PATH`.

| Platform | Archive |
|---|---|
| Linux x86_64 (glibc) | `agent86-v1.0.2-x86_64-unknown-linux-gnu.tar.gz` |
| macOS Apple silicon | `agent86-v1.0.2-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `agent86-v1.0.2-x86_64-apple-darwin.tar.gz` |
| Windows x86_64 | `agent86-v1.0.2-x86_64-pc-windows-msvc.zip` |

Each archive has a `.sha256` file next to it. The binaries are not signed:

- **macOS:** clear the quarantine flag once with `xattr -d com.apple.quarantine agent86`.
- **Windows:** SmartScreen may ask you to confirm the first time you run it.

To build from source instead, use Rust 1.88 or newer: `cargo install --git https://github.com/tdfleming/agent-86-rs --tag v1.0.2`.

See the [1.0.1 notes](https://github.com/tdfleming/agent-86-rs/releases/tag/v1.0.1) and the [1.0.0 notes](https://github.com/tdfleming/agent-86-rs/releases/tag/v1.0.0) for everything else included.
