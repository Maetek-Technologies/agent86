agent86 is now also a Rust library. [`agent86-core`](https://crates.io/crates/agent86-core) is the agent behind the CLI, published on crates.io, and its `sdk` module builds an agent inside your own program with the same workspace jail, approvals, sandbox, guardrails, and secret redaction the CLI has. The CLI itself is unchanged from 1.0.24.

## The library

```sh
cargo add agent86-core
```

- **`Agent::builder()`** takes a provider, a workspace, and whatever else you hand it, and reads nothing else: no config file, environment variable, home directory, keyring, or terminal.
- **Least authority by default.** No built-in tools unless you ask for them (`Builtins::ReadOnly`, `Files`, or `All`). Side-effecting calls go to your `approver` closure, with the same preview and diff the terminal shows; with no approver they are declined, as in a piped `agent86 run`.
- **Your own tools** from a closure and a JSON Schema (`FnTool`), or by implementing the `Tool` trait. Providers for OpenAI-compatible servers, Anthropic, Google, and Ollama are included, and `Provider` is a trait you can implement.
- **Everything else on request:** MCP servers (values taken literally, never expanded from your environment), long-term memory and resumable sessions in the CLI's own database format, skills, sub-agents and your own specialists (in parallel or in git worktrees), named models with triage routing, OpenTelemetry spans, and callbacks for the questions a turn asks mid-way: raising a limit it reached, or a secret the model needs.
- **Conversations** save to and load from JSON (`Conversation::to_json`), the same JSON the CLI's sessions keep.
- **A lighter build** with `default-features = false`, which leaves out the OS keyring and the local embedding model: about 170 dependencies instead of 370.

The crate's [README](https://github.com/Maetek-Technologies/agent86/blob/main/crates/agent86-core/README.md) has an example, [`examples/embed.rs`](https://github.com/Maetek-Technologies/agent86/blob/main/crates/agent86-core/examples/embed.rs) runs against any OpenAI-compatible endpoint, and [ADR 0003](https://github.com/Maetek-Technologies/agent86/blob/main/docs/adr/0003-embeddable-agent-api.md) explains the design.

## Stability

Only `agent86_core::sdk` is covered by semantic versioning. The crate's other modules are public because the agent86 binary is built on them; they are hidden from the documentation and may change in any release. The library and the CLI share one version number.

## The CLI

Nothing changes for CLI users: the interface, `run` and `run --json`, the ACP server, the config files, and the session, trace, and keyring formats are as they were in 1.0.24. Under the hood the repository is now a Cargo workspace of two crates, the library and the binary built on it.

The minimum supported Rust version is still 1.94.
