You can now give the agent a key, token, or password without typing it into the chat, and Ollama models keep the context window their Modelfile sets.

## What's new

- **Secure secret entry:** when the agent needs a secret, it asks for it with the new `request_secret` tool, and you type or paste the value into a masked prompt (a panel in the interface, a hidden prompt at the terminal). The agent only ever sees the secret's name.
  - `/secret NAME` enters one without being asked, `/secret` lists the names, and `/secret forget NAME` drops one. Secrets are held for the session only.
  - `run_command` and `python_exec` get each secret as an environment variable of that name. In the Docker sandbox it is passed by name, so the value never shows in a process list.
  - `write_file` and `edit_file` write the value wherever their arguments say `${secret:NAME}`, so the agent can put your key in `.env` without seeing it. The approval diff shows the placeholder.
  - Wherever the value would reach the model, the saved session, the prompt history, or the trace (tool output, your own messages, the model's reply), it is replaced by `${secret:NAME}`.
  - Piped and CI runs, where nobody can enter a value, are not offered the tool.

  This keeps secrets out of transcripts, provider logs, traces, and memory. It does not stop a hostile model, which could still get a transformed copy (base64, part of the value) past the replacement.
- **Ollama's Modelfile `num_ctx` is respected:** 1.0.2 capped every Ollama model at 32768 tokens and sent that size with each request, which overrode a larger `PARAMETER num_ctx` in the model's Modelfile. A Modelfile's own `num_ctx` is now used as is. Without one, the trained length up to `num_ctx_max` still applies, and `num_ctx` under `[providers.ollama]` still wins over both.

Secure secret entry is a deliberate addition beyond Python agent86, which has no way to hand the agent a secret except the chat. Everything else behaves as in 1.0.2.

## Install

Download the archive for your platform, extract it, and put `agent86` (or `agent86.exe`) on your `PATH`.

| Platform | Archive |
|---|---|
| Linux x86_64 (glibc) | `agent86-v1.0.3-x86_64-unknown-linux-gnu.tar.gz` |
| macOS Apple silicon | `agent86-v1.0.3-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `agent86-v1.0.3-x86_64-apple-darwin.tar.gz` |
| Windows x86_64 | `agent86-v1.0.3-x86_64-pc-windows-msvc.zip` |

Each archive has a `.sha256` file next to it. The binaries are not signed:

- **macOS:** clear the quarantine flag once with `xattr -d com.apple.quarantine agent86`.
- **Windows:** SmartScreen may ask you to confirm the first time you run it.

To build from source instead, use Rust 1.88 or newer: `cargo install --git https://github.com/Maetek-Technologies/agent86 --tag v1.0.3`.
