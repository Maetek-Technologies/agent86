The terminal tab now shows agent86, your folder, and whether agent86 is working or waiting for you.

## What's new

- **Terminal title:** the interface titles the tab `agent86 · <folder>`. While a turn runs it reads `✳ agent86 · <folder>`, and while the turn waits for you (an approval, an offer to raise a limit, or a secret) `⚠ agent86 · <folder>`, so another tab shows when agent86 needs you. On exit the tab gets its own title back. Before this, an npm install on Windows left the tab reading `C:\WINDOWS\system32\cmd.exe`.
- **npm packages with provenance:** from this release, the npm packages are published by the release workflow itself, with no stored token, and each carries a provenance statement linking it to the commit and workflow run that built it.

The terminal title is a deliberate addition beyond Python agent86. Everything else behaves as in 1.0.6.

## Install

```sh
npm install -g agent86
```

Already on 1.0.6? Run `/update now` in agent86, or `npm install -g agent86@latest`.

Or download the archive for your platform, extract it, and put `agent86` (or `agent86.exe`) on your `PATH`.

| Platform | Archive |
|---|---|
| Linux x86_64 (glibc 2.35+) | `agent86-v1.0.7-x86_64-unknown-linux-gnu.tar.gz` |
| Linux ARM64, including Raspberry Pi (glibc 2.35+) | `agent86-v1.0.7-aarch64-unknown-linux-gnu.tar.gz` |
| macOS Apple silicon | `agent86-v1.0.7-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `agent86-v1.0.7-x86_64-apple-darwin.tar.gz` |
| Windows x86_64 | `agent86-v1.0.7-x86_64-pc-windows-msvc.zip` |

Each archive has a `.sha256` file next to it. The binaries are not signed:

- **macOS:** clear the quarantine flag once with `xattr -d com.apple.quarantine agent86`.
- **Windows:** SmartScreen may ask you to confirm the first time you run it.
- **Raspberry Pi:** a headless Pi usually has no Secret Service, so `agent86 keys set` may fail there. Put the key in the provider's environment variable instead (for example `OPENROUTER_API_KEY`).

To build from source instead, use Rust 1.88 or newer: `cargo install --git https://github.com/Maetek-Technologies/agent86 --tag v1.0.7`.
