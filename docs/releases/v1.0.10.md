Show or hide the model's thinking and your tool calls, and a quieter default.

## What's new

- **Choose how much you see:** thinking models can fill the screen with reasoning, and a busy turn prints a line per tool call. Both now have three levels:
  - **Thinking:** `full` streams the reasoning dimmed, as before. `summary` prints one dim line when it ends (`∴ thought for 12s · 2.1k chars`). `hidden` prints nothing.
  - **Tool use:** `full` shows each call's arguments and the whole result. `summary` is the two lines per call you had. `hidden` prints nothing for calls that worked.
  - **Ctrl+T** cycles the thinking level while you watch. `/thinking` and `/toolview` set either one by name (a bare command shows the level), and `[ui] thinking` and `[ui] tool_use` set the defaults. `/thinking save` or `/toolview save` shows the config change and writes it for you.
- **Nothing important is hidden:** a failed tool call, a call that never got an answer, and every approval always show, and the status line still says `thinking` or `running <tool>`. Ctrl+O always has the full reasoning and every call, whatever the level.
- **Only the interactive interface changes.** `run`, `run --json`, and the plain loop print exactly what they did.
- **The header carries a copyright line** under the version, and the README has the logo.

## Quieter by default

Both settings default to `summary`, so after updating, reasoning appears as a single line instead of streaming. To get the old behaviour back, add this to your config:

```toml
[ui]
thinking = "full"
```

Or press Ctrl+T once or twice in the interface, and `/thinking save` to keep it.

## Install

```sh
npm install -g agent86
```

Or download the archive for your platform, extract it, and put `agent86` (or `agent86.exe`) on your `PATH`.

| Platform | Archive |
|---|---|
| Linux x86_64 (glibc 2.35+) | `agent86-v1.0.10-x86_64-unknown-linux-gnu.tar.gz` |
| Linux ARM64, including Raspberry Pi (glibc 2.35+) | `agent86-v1.0.10-aarch64-unknown-linux-gnu.tar.gz` |
| macOS Apple silicon | `agent86-v1.0.10-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `agent86-v1.0.10-x86_64-apple-darwin.tar.gz` |
| Windows x86_64 | `agent86-v1.0.10-x86_64-pc-windows-msvc.zip` |

Each archive has a `.sha256` file next to it. The binaries are not signed:

- **macOS:** clear the quarantine flag once with `xattr -d com.apple.quarantine agent86`.
- **Windows:** SmartScreen may ask you to confirm the first time you run it.
- **Raspberry Pi:** a headless Pi usually has no Secret Service, so `agent86 keys set` may fail there, and so will remembering a secret. Put the key in the provider's environment variable instead (for example `OPENROUTER_API_KEY`).

To build from source instead, use Rust 1.88 or newer: `cargo install --git https://github.com/Maetek-Technologies/agent86 --tag v1.0.10`.
