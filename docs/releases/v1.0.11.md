## What's new

- **A mascot in the header:** the interactive interface now opens with the logo's robot detective (fedora, silver face, cyan eyes) drawn in the terminal beside the `AGENT 86` wordmark. It needs a terminal 83 columns wide or more; from 64 columns you get the wordmark alone, as before, and narrower than that the one-line title.
- **Only the interactive interface changes.** `run`, `run --json`, and the plain loop print exactly what they did.
- **The README screenshot** shows the new header.

## Install

```sh
npm install -g agent86
```

Or download the archive for your platform, extract it, and put `agent86` (or `agent86.exe`) on your `PATH`.
