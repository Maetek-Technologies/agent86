Editors now show how full the context is and what a session has cost, and clients such as agent86-web can follow each model call, sub-agent, guardrail, and routing decision as it happens.

## Context and cost in your editor

- **A context meter and a running cost.** After each model call, agent86 tells the editor how much of the model's context window the last request used, how large the window is, and what the session has cost so far in US dollars. This uses ACP's standard `usage_update`, so an editor that shows context or cost needs nothing agent86-specific.
- **Unknown is not free.** For a model agent86 has no price for, the cost is left out rather than shown as zero, as the terminal shows `cost n/a`.
- **Compactions in their place.** When a long session is compacted into a summary, an editor that supports ACP's compaction updates shows it as one entry with the summary (or says why the summary could not be written). Other editors get the same one-line message as before.

## agent86's state, for clients that ask

- **An opt-in extension.** A client can ask for agent86's own state events (`com.maetek.agent86/state`). It then hears about every model call, the main agent's and each sub-agent's, with its cost, the turn's spend so far, and the cost limit. It also hears when each sub-agent starts and finishes, with what it cost and the card it reports on, about guardrail verdicts, and about which model triage routing chose.
- **Never more than the trace.** These events are the flight recorder's own, redacted exactly as `~/.agent86/traces/trace.jsonl` is: a secret appears as `${secret:NAME}`. They are sent whether or not the trace file is written.
- **Nothing changes for other clients.** Editors that do not ask see no new messages, apart from the extension being listed in `initialize`.
- The format is described in [the ACP guide](https://github.com/Maetek-Technologies/agent86/blob/main/docs/ACP.md#agent86s-state-an-extension).

## For client authors

- The marker for a session whose folder is unknown is now also sent as `"com.maetek.agent86/cwdKnown": false` in `session/list`. The older `agent86.cwdKnown` key is still sent and will be removed in a later release, so read the new one.

The terminal interface and `agent86 run` are unchanged.
