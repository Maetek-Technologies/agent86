A small update to the interactive interface. Nothing else changes: `run`, `run --json`, the plain REPL, the config, and the shared files behave exactly as in 1.0.0.

## What's new

- **A new startup header:** a block-letter `AGENT 86` wordmark in a cyan-to-violet gradient, with the version and the working directory under it. On a terminal too narrow for the wordmark, it is one line instead.
- **The working directory is always on screen:** it sits in the input box's top border, right-aligned, with your home folder shown as `~`. When the box is narrow, it shows only the folder's name.

The status line is unchanged from Python's. The model is shown there, not in the header, so `/model` keeps it current.

## Install

Download the archive for your platform, extract it, and put `agent86` (or `agent86.exe`) on your `PATH`.

| Platform | Archive |
|---|---|
| Linux x86_64 (glibc) | `agent86-v1.0.1-x86_64-unknown-linux-gnu.tar.gz` |
| macOS Apple silicon | `agent86-v1.0.1-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `agent86-v1.0.1-x86_64-apple-darwin.tar.gz` |
| Windows x86_64 | `agent86-v1.0.1-x86_64-pc-windows-msvc.zip` |

Each archive has a `.sha256` file next to it. The binaries are not signed:

- **macOS:** clear the quarantine flag once with `xattr -d com.apple.quarantine agent86`.
- **Windows:** SmartScreen may ask you to confirm the first time you run it.

To build from source instead, use Rust 1.88 or newer: `cargo install --git https://github.com/Maetek-Technologies/agent86 --tag v1.0.1`.

## Version

1.0.0 matched Python agent86's version. From 1.0.1 the two are numbered independently, so the environment line in the system prompt reports `agent86 v1.0.1`. Compatibility with Python agent86 1.0.0 is unchanged.
