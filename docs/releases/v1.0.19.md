The agent can now search your project without running commands, and editors show its file edits as diffs you can review.

## Search tools

- **`search_files`** finds a regular expression in your files and returns the matching lines as `path:line: text`, grouped by file. It can be limited to a folder, a file, or a glob (`src/**/*.rs`), ignore case, and show lines of context around each match.
- **`find_files`** finds files by glob: `src/**/*.rs`, or `*.toml` for every TOML file anywhere.
- **No approval needed.** Both only read, so they are never asked about, and several can run at once. Until now the agent searched with `grep`, `find`, or `rg` through `run_command`, which needed your approval, depended on what was installed, and behaved differently on Windows.
- **They skip what you would skip.** `.gitignore`, `.ignore`, and git's global excludes are respected, whether or not the folder is a git repository. Version-control folders (`.git`, `.hg`, `.svn`, `.jj`) and binary files are never searched. Hidden files and folders such as `.github/` are searched, so keep secret files like `.env` in `.gitignore`.
- **They stay in your project.** Searches cannot leave the workspace, and symlinks pointing outside it are not followed.
- **Stable, bounded output.** Paths are relative to the project, with `/` on every OS, and always in the same order. Results stop at 200 by default (up to 2000), long lines are cut, files over 2 MiB are skipped, and a search stops after 20,000 files. Whenever something is cut, the result says so and how to narrow the search.
- The built-in `planner`, `researcher`, and `reviewer` specialists can use both.

## File edits as diffs in editors

- **Review the change, not a wall of text.** When the agent writes or edits a file, editors that speak ACP now get the change as a diff of the whole file, before and after. That covers both the permission request and the finished tool call. The text shown until now is still sent beside it, for editors that do not show diffs. Files over 256 KiB are shown as text only.
- **Follow along.** File reads and writes now tell the editor which file they touch and, for a write, the first changed line, so an editor can jump there. Searches are marked as searches.
- **Secrets stay hidden.** A secret written into a file with `${secret:NAME}` appears in every diff as `${secret:NAME}`, never as its value.
- A reopened editor thread shows earlier edits as text, without diffs.

The terminal interface and `agent86 run` are unchanged.
