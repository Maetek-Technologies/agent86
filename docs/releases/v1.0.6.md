agent86 now installs and updates with npm, tells you when a newer release is out, and is the standard agent86: this repository is public at Maetek-Technologies/agent86, and the original Python implementation is archived.

## What's new

- **Install with npm:** `npm install -g agent86` installs the native binary for your platform, and `npm install -g agent86@latest` updates it. npm needs Node.js 18 or newer only to install and launch agent86; agent86 itself still needs no Python or Node.
- **New-version notice:** the interface and the plain loop check GitHub for a newer release at most once a day, and say so when there is one. `run` and `run --json` never check. Turn it off with `[ui] update_check = false` or `AGENT86_NO_UPDATE_CHECK=1`.
- **`/update`:** says whether you have the latest release, and how to update for the way you installed agent86: npm, `cargo install`, or a downloaded archive. `/update now` runs the update (or, for an archive, opens the release page); restart agent86 afterwards to use the new version.
- **The standard agent86:** this is now the agent86, at [Maetek-Technologies/agent86](https://github.com/Maetek-Technologies/agent86). The Python implementation is archived as [agent86-python](https://github.com/Maetek-Technologies/agent86-python). To switch from it, `pip uninstall agent86` (or `pipx uninstall agent86`) first, since both install an `agent86` command; your `~/.agent86` config, sessions, memory, traces, and keyring keys carry over as they are.

The notice and `/update` are deliberate additions beyond Python agent86. Everything else behaves as in 1.0.5.

## Install

```sh
npm install -g agent86
```

Or download the archive for your platform, extract it, and put `agent86` (or `agent86.exe`) on your `PATH`.

| Platform | Archive |
|---|---|
| Linux x86_64 (glibc 2.35+) | `agent86-v1.0.6-x86_64-unknown-linux-gnu.tar.gz` |
| Linux ARM64, including Raspberry Pi (glibc 2.35+) | `agent86-v1.0.6-aarch64-unknown-linux-gnu.tar.gz` |
| macOS Apple silicon | `agent86-v1.0.6-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `agent86-v1.0.6-x86_64-apple-darwin.tar.gz` |
| Windows x86_64 | `agent86-v1.0.6-x86_64-pc-windows-msvc.zip` |

Each archive has a `.sha256` file next to it. The binaries are not signed:

- **macOS:** clear the quarantine flag once with `xattr -d com.apple.quarantine agent86`.
- **Windows:** SmartScreen may ask you to confirm the first time you run it.
- **Raspberry Pi:** a headless Pi usually has no Secret Service, so `agent86 keys set` may fail there. Put the key in the provider's environment variable instead (for example `OPENROUTER_API_KEY`).

To build from source instead, use Rust 1.88 or newer: `cargo install --git https://github.com/Maetek-Technologies/agent86 --tag v1.0.6`.
