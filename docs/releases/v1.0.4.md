Thinking models no longer end a turn with an empty answer, the interface shows their reasoning, and the agent now knows the date and time, so it can tell when a result is stale.

## What's new

- **Reasoning is shown:** the interface streams a thinking model's reasoning, dimmed under a `∴` marker. It stays in the Ctrl+O transcript. Ollama's `thinking`, the OpenAI-compatible `reasoning_content` and `reasoning` (llama.cpp, vLLM, DeepSeek, OpenRouter), and Anthropic thinking blocks are all read. `run`, `run --json`, and the plain loop are unchanged.
- **No more empty answers:** some thinking models put their whole answer in their reasoning and reply with nothing. When a final reply is empty, the agent now asks once more (`[no answer; asking the model again]`). If the reply is still empty, the reasoning stands in for the answer (`[no answer; showing the model's reasoning]`). Sub-agents do the same, and hand their reasoning back to the agent that delegated to them, marked as reasoning.
- **The agent knows the time:** each turn tells the model the current local date and time, and UTC. A model can now tell that a page cached hours ago is stale, or what "today" means.
- **Default arguments for MCP tools:** `[mcp.servers.<name>.defaults]` adds arguments the model leaves out, by tool. Only arguments the tool declares are added, and the model's own values win. For example, to make Firecrawl always scrape a fresh page rather than its cache:

  ```toml
  [mcp.servers.Firecrawl.defaults]
  firecrawl_scrape = { maxAge = 0 }
  ```

All four are deliberate additions beyond Python agent86. Everything else behaves as in 1.0.3.

## Install

Download the archive for your platform, extract it, and put `agent86` (or `agent86.exe`) on your `PATH`.

| Platform | Archive |
|---|---|
| Linux x86_64 (glibc) | `agent86-v1.0.4-x86_64-unknown-linux-gnu.tar.gz` |
| macOS Apple silicon | `agent86-v1.0.4-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `agent86-v1.0.4-x86_64-apple-darwin.tar.gz` |
| Windows x86_64 | `agent86-v1.0.4-x86_64-pc-windows-msvc.zip` |

Each archive has a `.sha256` file next to it. The binaries are not signed:

- **macOS:** clear the quarantine flag once with `xattr -d com.apple.quarantine agent86`.
- **Windows:** SmartScreen may ask you to confirm the first time you run it.

To build from source instead, use Rust 1.88 or newer: `cargo install --git https://github.com/Maetek-Technologies/agent86 --tag v1.0.4`.
