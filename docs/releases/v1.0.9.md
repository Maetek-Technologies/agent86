Secrets can be remembered per project, and tool arguments a model sends as JSON strings are repaired.

## What's new

- **Remember a secret for the project:** when you enter a secret (the agent's `request_secret`, or `/secret NAME`), you can choose to remember it: Tab toggles "Remember for this project" in the panel, and a terminal asks `[y/N]`. The value goes into the OS keyring under a key made from the workspace's path, and is loaded again whenever agent86 starts at a terminal in that directory. The model still only ever sees the name. `/secret` marks the remembered ones, and `/secret forget NAME` removes the keyring entry too. Without a keyring the choice isn't offered, and piped or CI runs never read or write it.
- **JSON-string arguments are repaired:** some models send an array or an object argument as a JSON string (`"[\"markdown\"]"` where the tool wants `["markdown"]`), which the tool rejected and the turn lost a step. When a tool's schema wants an array or an object and the string parses as one, agent86 now uses the parsed value, for built-in and MCP tools. A `tool_args_repaired` event in the trace records it. Anything that doesn't parse fails with the same message as before.

## Under the hood

- The release workflows now use GitHub Actions that run on Node 24 (`checkout` v7, `upload-artifact` v7, `download-artifact` v8, `setup-node` v7), ahead of Node 20's removal.

## Install

```sh
npm install -g agent86
```

Or download the archive for your platform, extract it, and put `agent86` (or `agent86.exe`) on your `PATH`.

| Platform | Archive |
|---|---|
| Linux x86_64 (glibc 2.35+) | `agent86-v1.0.9-x86_64-unknown-linux-gnu.tar.gz` |
| Linux ARM64, including Raspberry Pi (glibc 2.35+) | `agent86-v1.0.9-aarch64-unknown-linux-gnu.tar.gz` |
| macOS Apple silicon | `agent86-v1.0.9-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `agent86-v1.0.9-x86_64-apple-darwin.tar.gz` |
| Windows x86_64 | `agent86-v1.0.9-x86_64-pc-windows-msvc.zip` |

Each archive has a `.sha256` file next to it. The binaries are not signed:

- **macOS:** clear the quarantine flag once with `xattr -d com.apple.quarantine agent86`.
- **Windows:** SmartScreen may ask you to confirm the first time you run it.
- **Raspberry Pi:** a headless Pi usually has no Secret Service, so `agent86 keys set` may fail there, and so will remembering a secret. Put the key in the provider's environment variable instead (for example `OPENROUTER_API_KEY`).

To build from source instead, use Rust 1.88 or newer: `cargo install --git https://github.com/Maetek-Technologies/agent86 --tag v1.0.9`.
