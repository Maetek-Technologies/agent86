# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which is incorporated here by reference.

In short: be respectful and constructive, welcome people of every background and experience level, accept feedback gracefully, and focus on what is best for the community. Harassment, discrimination, personal attacks, and publishing others' private information are not acceptable.

## Reporting and enforcement

Report unacceptable behavior to **tony@maetek.com**. Reports are handled privately, and the project maintainers decide on and apply the consequences, as described in the Covenant's enforcement guidelines.
